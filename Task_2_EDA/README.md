## 📌 Task 2 – E-Commerce Sales Data Analysis (EDA)

This project is part of my CodeAlpha Data Analytics Internship.

### 🔍 Project Overview
Performed Exploratory Data Analysis (EDA) on e-commerce sales data using Python and Pandas.

### 🛠️ Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

### 📊 Analysis Performed
- Data cleaning and missing-value handling
- Monthly revenue analysis
- Category-wise revenue analysis
- City-wise revenue analysis
- Product-wise revenue analysis
- Quantity and quarterly analysis
- Outlier detection using IQR

- `CodeAlpha_ECommerce_EDA.ipynb` – EDA Notebook
