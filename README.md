# CodeAlpha E-Commerce Sales Data Visualization

## 📌 Project Overview

This project is part of my CodeAlpha Data Analytics Internship.

The project focuses on analyzing e-commerce sales data and creating visualizations to understand revenue trends and sales performance.

## 📊 Dataset

The dataset contains 1,500 e-commerce sales records with information such as:

- Order ID
- Order Date
- City
- Category
- Product
- Quantity
- Unit Price
- Discount
- Revenue
- Month
- Quarter

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Excel

## 📈 Visualizations

The project includes the following visualizations:

1. Monthly Revenue Trend
2. Revenue by Category
3. Revenue by City
4. Top 10 Products by Revenue
5. Revenue by Quantity
6. Revenue by Quarter
7. E-Commerce Sales Dashboard

💡 Project Insights

The visualizations help understand:

- Monthly revenue trends
- Category-wise sales performance
- City-wise revenue
- Product performance
- Quarterly revenue patterns
- Overall e-commerce sales performance
